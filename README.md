## Project Context & Goals

This repository contains the data science project for the Data Science course focused on analyzing lap timing and telemetry data from the Formula 1 Singapore Grand Prix using the FastF1 API.

### Project Goals

* **Goal 1: Impact of Mercedes upgrades.** Analyze the telemetry of Mercedes drivers using different aerodynamic/spec upgrades during the Singapore GP to quantify how car performance differ between specifications.
* **Goal 2: Mercedes Engine Performance across teams.** Four out of ten teams use Mercedes power units. By isolating engine performance, we evaluate which telemetry details create performance gaps between these teams.
* **Goal 3: Red Bull drivers driving style.** Compare telemetry between Red Bull drivers to analyze how individual driving styles affect lap times on a street circuit.
